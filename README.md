# 🧮 Calculadora Universal - UTM

## 📌 Descripción del Proyecto

Calculadora Universal es una aplicación web desarrollada con tecnologías frontend modernas:

- HTML5
- CSS3
- JavaScript

El sistema fue diseñado como una calculadora científica multifuncional con interfaz moderna, responsive y orientada al uso académico.

El proyecto incluye:

- Calculadora científica
- Conversor de masa
- Conversor de unidades
- Conversor de temperatura
- Historial de operaciones
- Sistema de favoritos
- Ajustes básicos
- Panel de ayuda
